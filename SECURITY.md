# Security Policy

Author: Nicholas Corrieri  
GitHub: @nickcorrieri  
Owner: InnoNotion LLC

RAWDOG is local-first CLI software. It does not run a hosted service, daemon,
account system, browser application, or cloud sync process.

## Reporting Issues

Report security concerns privately to InnoNotion LLC or @nickcorrieri before
public disclosure when practical.

Include:

- affected RAWDOG version or commit;
- operating system;
- command used;
- paths involved, redacted as needed;
- expected behavior;
- observed behavior;
- whether files were copied, overwritten, renamed, deleted, or exposed.

## Safety Expectations

RAWDOG security work prioritizes:

- preventing archive deletion;
- preventing archive overwrite;
- avoiding path traversal;
- avoiding accidental writes outside configured roots;
- keeping reports free of unnecessary private data;
- keeping destructive flags unsupported.

## No Warranty

Security reporting does not create an obligation to provide fixes, support,
maintenance, migration assistance, data recovery, or compensation.
